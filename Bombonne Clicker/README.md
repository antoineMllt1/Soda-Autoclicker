# Bombonne Clicker — The Best Minecraft PvP Autoclicker

**Bombonne Clicker** is a premium, open-source auto-clicker designed for **Minecraft Java Edition 1.8.9 PvP**.  
Built by **Antoine** to give you the ultimate competitive edge.

## Features

- **Undetectable**: Bypasses everything (Hypixel, MMC, etc).
- **Auto-Rod**: Perfect rod clicks every time.
- **Jitter Simulation**: Makes your clicks look legit.
- **Bombonne Mode**: Special algorithms for maximum reach and combo potential.
- **Sleek Interface**: Beautiful purple theme by default.

## Usage

Simply run `python main.py` and enjoy.
